# 🧮 CloudGraph — Core Formulas & Mathematical Framework

This document details the mathematical framework, variable derivations, step-by-step worked examples, and academic literature references for all ranking, verification, and evaluation algorithms in **CloudGraph**.

## 1. Hybrid Ranker Score ($S_{\text{hybrid}}$)

Fuses dense vector similarity, graph topology proximity, and exponential time-decay into a unified retrieval score.

### Plain Text Formula (Code Block)

```text
Hybrid_Score = (0.50 * Vector_Similarity) + (0.30 * Graph_Proximity) + (0.20 * Recency_Decay)

Where:
Graph_Proximity = 1 / (1 + Hop_Distance)
Recency_Decay   = exp( - (0.6931 * Time_Difference_in_Seconds) / 3600 )
```

### LaTeX Notation

$$S_{\text{hybrid}} = 0.50 \cdot S_{\text{vector}} + 0.30 \cdot S_{\text{graph}} + 0.20 \cdot S_{\text{recency}}$$

$$S_{\text{graph}} = \frac{1}{1 + \text{hop\_distance}}, \qquad S_{\text{recency}} = \exp\left(-\frac{\ln 2 \cdot \Delta t}{3600}\right)$$

### Variable Derivations & Provenance

* `Vector_Similarity` ($S_{\text{vector}}$): Cosine similarity calculated in **Qdrant** using 384-dimensional dense embeddings generated by `sentence-transformers/all-MiniLM-L6-v2` ([Reimers & Gurevych, 2019](#-references)).
* `Graph_Proximity` ($S_{\text{graph}}$): Topological hop distance measured in **Neo4j** via Cypher `shortestPath()` queries from the incident target pod.
* `Recency_Decay` ($S_{\text{recency}}$): Half-life exponential decay ($T_{1/2} = 3600\text{ seconds}$) calculated between the evidence timestamp and the incident start epoch.

### Step-by-Step Worked Example

For an incident log entry with `Vector_Similarity = 0.80`, `Hop_Distance = 1` (`Graph_Proximity = 1 / (1+1) = 0.50`), and `Time_Difference = 0` (`Recency_Decay = 1.00`):

```text
Hybrid_Score = (0.50 * 0.80) + (0.30 * 0.50) + (0.20 * 1.00)
             = 0.40 + 0.15 + 0.20
             = 0.75
```

## 2. GPCS Trust Score (Graph-Provenance Claim Scoring)

Evaluates whether an individual atomic claim $c_i$ in an LLM report is grounded in Neo4j and Qdrant telemetry evidence at **zero LLM call cost**.

### Plain Text Formula (Code Block)

```text
Trust_Score = (0.45 * Vector_Sim) + (0.35 * Graph_Prox) + (0.25 * Source_Reliability) - Penalty

Where:
Graph_Prox         = 1 / (1 + Min_Hop_Distance)
Penalty            = 0.15 * (Min_Hop_Distance * 0.05)
Source_Reliability = Metric (0.95), Log (0.85), Topology (0.80), Commit (0.70)

Decision Rule: If Trust_Score >= 0.50 -> SUPPORTED (False), else -> UNSUPPORTED (True)
```

### LaTeX Notation

$$\text{trust\_score}(c_i) = 0.45 \cdot \text{similarity} + 0.35 \cdot \text{proximity} + 0.25 \cdot \text{reliability} - \text{penalty}$$

$$\text{gpcs\_unsupported}(c_i) = \begin{cases} \text{False (SUPPORTED)} & \text{if } \text{trust\_score}(c_i) \ge 0.50 \\ \text{True (UNSUPPORTED)} & \text{if } \text{trust\_score}(c_i) < 0.50 \end{cases}$$

### Variable Derivations & Provenance

* `Vector_Sim`: Maximum cosine similarity match in Qdrant across all retrieved evidence vectors for claim $c_i$.
* `Graph_Prox`: Shortest graph path distance in Neo4j between the claim entity (e.g., `checkoutservice`) and evidence node.
* `Source_Reliability`: Fixed system reliability weights: Prometheus Metric (`0.95`), Loki Log (`0.85`), Topology (`0.80`), Commit (`0.70`).
* `Penalty`: Hop-distance penalty ($0.15 \times \text{hop} \times 0.05$) preventing multi-hop hallucination leaps.

### Step-by-Step Worked Example

Claim: *"checkoutservice resource utilization spiked"*:

* `Vector_Sim = 0.7500`, `Min_Hop = 1` (`Graph_Prox = 0.5000`), `Source_Reliability = Metric (0.8500)`, `Penalty = 0.15 * (1 * 0.05) = 0.0075`.

```text
Trust_Score = (0.45 * 0.7500) + (0.35 * 0.5000) + (0.25 * 0.8500) - 0.0075
            = 0.3375 + 0.1750 + 0.2125 - 0.0075
            = 0.7175  (--> SUPPORTED, since 0.7175 >= 0.50)
```

## 3. Self-Consistency Recurrence Score

Measures whether an extracted atomic claim $c_i$ recurs across independent LLM generations at temperature $T=0.8$.

### Plain Text Formula (Code Block)

```text
Recurrence_Score = Matching_Runs_Count / (Total_Runs - 1)

Where a run matches if max( Cosine_Similarity( Claim_Run1, Claim_RunK ) ) >= 0.80.
Decision Rule: If Recurrence_Score >= 0.50 -> SUPPORTED (False), else -> UNSUPPORTED (True)
```

### LaTeX Notation

$$\text{recurrence}(c_i) = \frac{\sum_{k=2}^{K} \mathbb{I}\left(\max_{c \in C_k} \text{cosine\_sim}(c_i, c) \ge 0.80\right)}{K - 1}$$

$$\text{sc\_unsupported}(c_i) = \begin{cases} \text{False (SUPPORTED)} & \text{if } \text{recurrence}(c_i) \ge 0.50 \\ \text{True (UNSUPPORTED)} & \text{if } \text{recurrence}(c_i) < 0.50 \end{cases}$$

### Variable Derivations & Provenance

* `Total_Runs`: Total diagnostic generations executed ($K = 3$).
* `Matching_Runs_Count`: Pairwise `all-MiniLM-L6-v2` embedding vector similarity match count ($\ge 0.80$ threshold).

### Step-by-Step Worked Example

For a claim generated in Run 1 across 3 total runs:

* Found matching claim in Run 2 (`Sim = 0.94 >= 0.80`) $\rightarrow$ Match 1
* Found matching claim in Run 3 (`Sim = 0.88 >= 0.80`) $\rightarrow$ Match 2

```text
Recurrence_Score = (1 + 1) / (3 - 1)
                 = 2 / 2
                 = 1.00  (--> SUPPORTED)
```

## 4. Graph Confidence Propagation (GCP)

Propagates anomaly confidence across Kubernetes topology using Noisy-OR probability logic.

### Plain Text Formula (Code Block)

```text
Propagated_Belief = 1 - PRODUCT_OVER_NEIGHBORS( 1 - (Link_Weight * Neighbor_Belief) )

Where:
Link_Weight = Hop_Decay ^ Hop_Distance
```

### LaTeX Notation

$$P(\text{anomaly at node } v) = 1 - \prod_{u \in \text{Neighbors}(v)} \left(1 - w_{u \to v} \cdot P(u)\right)$$

## 5. Verifier Evaluation Metrics

Evaluates accuracy and error detection performance against held-out ground truth labels.

### Plain Text Formulas (Code Block)

```text
Precision = True_Positives / (True_Positives + False_Positives)
Recall    = True_Positives / (True_Positives + False_Negatives)
F1_Score  = (2 * Precision * Recall) / (Precision + Recall)
Coverage  = (Consistent_Claims + Contradicted_Claims) / Total_Extracted_Claims * 100%
```

### LaTeX Notation

$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}, \qquad \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}, \qquad \text{F1} = \frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$$

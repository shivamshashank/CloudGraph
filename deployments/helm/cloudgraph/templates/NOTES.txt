1. Get the CloudGraph UI URL:
{{- if .Values.cloudgraphUI.ingress.enabled }}
  URL: http://{{ (first .Values.cloudgraphUI.ingress.hosts).host }}
{{- else }}
  kubectl port-forward -n {{ .Values.global.namespace }} svc/cloudgraph-ui 3000:3000
  Then access: http://localhost:3000
{{- end }}

2. Check deployment status:
  kubectl get deployments -n {{ .Values.global.namespace }}
  kubectl get pods -n {{ .Values.global.namespace }}

3. View CloudGraph API logs:
  kubectl logs -n {{ .Values.global.namespace }} deployment/cloudgraph-api -f

4. View Investigation Engine logs:
  kubectl logs -n {{ .Values.global.namespace }} deployment/investigation-engine -f

5. Access Neo4j Browser:
  kubectl port-forward -n {{ .Values.global.namespace }} svc/cloudgraph 7474:7474
  Then access: http://localhost:7474

6. Get Neo4j password:
  kubectl get secret -n {{ .Values.global.namespace }} cloudgraph-neo4j-auth -o jsonpath='{.data.neo4j-password}' | base64 -d

Thank you for installing CloudGraph! 🚀
Documentation: https://github.com/shivamshashank/CloudGraph/docs
